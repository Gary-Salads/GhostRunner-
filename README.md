# GhostRunner-
Used linear regression model trained on 2026,2025, and 2024 pitch data. Used regression model on live data to predict batter's scoring chance per pitch. Created a review program that turns the data from the live game to readable graphs that can be interpreted. Regression model takes into account base state, outs, strikes, balls, batter's xwoba for left handed or right handed pitchers, and pitcher's xwoba allowed for left handed and right handed batters. Checked model accuracy with log-loss, Brier score, and ROC-AOC.
